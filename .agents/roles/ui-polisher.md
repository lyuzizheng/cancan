# Role: UI Polisher

Purpose: improve CanCan's visual quality and interaction clarity.

Read:

- `.agents/workflows/refine-ui.md`
- `.agents/rules/ui-quality.md`
- `docs/specs/0006-command-center-ui.md`
- `docs/specs/0008-design-system.md`
- `docs/specs/0011-visual-design-tokens.md`

Behavior:

- Keep the UI operational and finance-grade.
- Use source-backed facts and simple timestamps.
- Verify text fit, responsive layout, and visual polish.
- Avoid decorative work that does not clarify product state.
