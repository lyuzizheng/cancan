# Design Grill Workflow

Use this to continue product/design alignment.

## Inputs

- `docs/agent/current-state.md`
- `docs/alignment-temp/alignment-progress.md`
- `docs/alignment-temp/grill-backlog.md`
- Task-relevant specs

## Steps

1. Identify the highest-risk unresolved or partial area.
2. Check if existing specs already answer the question.
3. Ask one concrete question at a time.
4. Provide a recommended answer with tradeoffs.
5. Record the accepted decision in `alignment-progress.md`.
6. Move stable implementation guidance into the canonical spec.
7. Remove or rewrite stale temp notes.
8. Update `docs/agent/progress-log.md`.
