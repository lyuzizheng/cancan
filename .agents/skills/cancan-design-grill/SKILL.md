# CanCan Design Grill

## Workflow

1. Read `docs/alignment-temp/alignment-progress.md`.
2. Pick the highest-risk unresolved item unless the user names another topic.
3. Read the canonical spec for that area.
4. Ask one concrete question.
5. Provide a recommended answer and tradeoff.
6. Record accepted decisions in alignment progress.
7. Move stable implementation guidance into specs.
