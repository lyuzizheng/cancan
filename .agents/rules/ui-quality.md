# UI Quality Rules

- Use left sidebar plus main body for core desktop UI.
- Command Center emphasizes Money Overview, source activity, timestamps, AI insight, and compact review state.
- Prefer Warm Off-White, graphite text, green semantic accent, amber review states, and red only for real risk/errors.
- Avoid giant hero cards, decorative gradients, glassmorphism defaults, busy card grids, cute illustrations, and unmodified component-library appearance.
- Use source-backed facts. Do not show invented AI labels, undefined freshness scores, or unsupported valuations.
- UI changes must include empty, loading, error, and reduced-motion states where relevant.
- Inspect UI visually before marking a UI task done.
