# Project Resources

This directory stores non-runtime project artifacts that preserve design and research decisions.

- [`design/vault-archive-2026-07/`](design/vault-archive-2026-07/README.md) contains the Source/Documents visual exploration that established CanCan's `Precision Vaultpunk` direction.
- [`shortcuts/`](shortcuts/README.md) contains the versioned `Save to CanCan Inbox` Share-sheet Shortcut, its manifest, and its install and real-device test path.

[Spec 0017](../docs/specs/0017-evidence-documents-source-ux.md) promotes the single Shortcut artifact to an application asset: the desktop host embeds those exact bytes and installs them on request.

Resources are not application assets unless an implementation spec explicitly promotes one. Production UI must remain semantic, accessible, and code-native.
