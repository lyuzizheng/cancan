# Current State

Last updated: 2026-08-08

## Product phase

CanCan has crossed from documentation/design alignment into production implementation. The app foundation, synthetic core flow, production Vault storage, first user-facing manual-evidence path, mock-only cloud OCR provider contract, reusable cloud OCR transport executor, and production review/ledger host boundary and renderer are complete. The merged Local Inbox checkpoint covers authorization, stable capture, parse/reconcile chaining, review-only provider profiles, versioned structured records, first-account confirmation, cross-month historical repayment matching, explicit commit to Activity, and repeat-scan idempotency. The completed post-PR41 hardening implementation adds filesystem-change wake-up hints, metadata-assisted startup scans, optional-capability failure isolation, versioned per-candidate account decisions, durable asynchronous parse jobs and explicit reparse history, and truthful preview/file-size evidence. Full local gates and independent review pass. The 2026-07-28 maintainer exception under `0016` was for PR45's hosted jobs, which ended before executing due to billing/spending-limit reasons; it has been lifted because PR58's hosted fast and native application gates started and passed. The exception record does not represent hosted CI as green for any later branch unless the owner separately records another exception. Statement coverage is a separate future AI-assisted source-analysis feature rather than part of Local Inbox completion. Three provider packages remain deterministic and uncalibrated for auto-commit; live-model normalization, cloud OCR app/runtime wiring, and a live-provider smoke have not started.

The current product target is an inbox-first local financial evidence vault and polished personal finance/account-record workspace with AI-assisted parsing, deterministic validation, policy-gated ledger commit, and source-backed money views. Phase 1 acquisition is user-downloaded evidence through Add/Open With and the official phone Share Shortcut into the user-authorized [CanCan iCloud Drive root](../specs/0017-evidence-documents-source-ux.md#user-authorized-cancan-icloud-drive-root). Gmail remains an optional capability whose public readiness is independent; it is no longer a Phase 1 acquisition or first-preview blocker. Every enabled channel still converges on the same evidence pipeline. MVP has no hosted service/backend; Gmail, BYO AI, optional fixed FX rates, update checks, and future connectors are capability-scoped local-client connections controlled by the user. An optional paid CanCan AI relay is an allowed post-MVP direction only; it must reuse the provider-adapter/capability boundary and has no current runtime, account, payment, or entitlement implementation.
