# Support

Where to get help with CanCan, in order of preference:

1. **Questions and how-to** — [GitHub Discussions](https://github.com/lyuzizheng/cancan/discussions), `Questions` category. This is the first stop for usage and support questions; answers stay searchable for everyone.
2. **Early ideas and design discussion** — Discussions, `Ideas` category. Proposals that are still taking shape belong here, not in issues.
3. **Reproducible bugs** — [Issues](https://github.com/lyuzizheng/cancan/issues) using the bug report form. Include version, operating system and architecture, reproduction steps, and expected/actual behavior. Redact all financial data, account numbers, and secrets — never attach real statements.
4. **Security vulnerabilities** — always private, never an issue or discussion. See [SECURITY.md](SECURITY.md).

The address `support@cancan.money` is intended as a support contact and is being provisioned; it is not yet monitored. Until it is verified, GitHub is the authoritative support channel.

User-facing documentation for the capabilities that actually ship lives on the project website's documentation page; the authoritative source of truth for intended behavior is `docs/specs/` in this repository.
